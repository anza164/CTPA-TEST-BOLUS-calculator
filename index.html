Bae's Standard Formula (Hardware Compensated):

TPEAK = TID + TARR - 5.3  |  TDELAY = TPEAK - ½ TSD - TSYS

Source: Read from single-ROI MPA curve. Second when HU begins to sharply rise.

Standardized Protocol: Programmed flow rate set on power injector (Default: 4.5 mL/s).

Protocol Volume: Default 30 mL (Editable for site-specific protocol adaptation).

Source: Pure X-ray acquisition time read from CT diagnostic protocol card.

Pre-scan Latency: Hardware delay for tube spin-up, table feed, & breath-hold command (Default: 2.0s).

Precision Tideal Spatial-Temporal Formula:

TDELAY = Tideal - ½ TSD - TSYS

Protocol: 20 mL Test (+ 20 mL Saline @ 4.5 mL/s) + 20 mL Diagnostic (+ 30 mL Saline @ 4.5 mL/s)

Source: Timestamp where MPA peak enhancement is optimal prior to aortic enhancement.

Source: Pure acquisition time read from CT protocol card.

Pre-scan Latency: Hardware delay for tube spin-up, table movement, & breath-hold audio (Default: 2.0s).

Calculation Summary:

Recommended Console Scan Delay (TDELAY): 0.0 s

Step 1: Test Bolus Monitoring Scan Setup

  • Position dynamic monitoring slice at the level of the Main Pulmonary Artery (MPA) trunk / Carina.
  • Engine A (Bae): Inject 20 mL contrast (370 mgI/mL) + 20 mL saline @ 4.5 mL/s.
  • Engine B (Tideal Protocol): Inject 20 mL contrast (370 mgI/mL) + 20 mL saline @ 4.5 mL/s.
  • Start low-dose monitoring scans simultaneously with contrast injection.

Step 2: ROI Placement & Curve Generation

Figure: Anatomical ROI Placement & Time-Density Curves (TDC) for CTPA Timing.
1. Bae Equation Method (Single Vessel): Axial CT image demonstrating a single circular ROI located in the Main Pulmonary Artery (MPA, red). The single-line TDC curve identifies contrast arrival time (TARR).
2. Tideal Protocol (Multi-Vessel): Axial CT image showing ROIs in the MPA (red), Ascending Aorta, and SVC. The TDC tracks arterial enhancement, identifying Tideal prior to aortic enhancement while verifying SVC attenuation (<350 HU).

Engine A (Single ROI - Bae):

1. Draw ROI 1 (Red) inside MPA trunk (~80-100 mm²).

2. Generate single Time-Enhancement Curve (TEC).

3. Identify TARR (second when HU begins rapid rise).

Engine B (3-Vessel - Tideal Protocol):

1. Monitor MPA, Ascending Aorta, and SVC.

2. Identify Tideal (second where MPA reaches maximum peak prior to aortic enhancement).

3. Verify SVC attenuation (<350 HU) to prevent RPA streak artifacts.

Step 3: Scan Duration & Hardware Latency Input

  • Obtain Pure Scan Duration (TSD) from diagnostic acquisition protocol card.
  • Set Scanner System Latency (TSYS) pre-scan delay (Default: 2.0s for tube spin-up, table feed, and audio prompt).
  • Enter values into the calculator above to derive TDELAY.

Step 4: Scanner Console Setup & Diagnostic Execution

  • Enter the calculated TDELAY value directly into the CT scanner console.
  • Program contrast injector for diagnostic scan at a flow rate of 4.5 mL/s:
    • Engine A (Bae Protocol): 30 mL contrast volume + 35 mL saline chaser
    • Engine B (Tideal Protocol): 20 mL contrast volume + 30 mL saline chaser
  • Press Injector Start and CT Scanner Start simultaneously to initiate diagnostic acquisition.
